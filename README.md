# 💰 Бот-напоминалка о платежах клиентов

Профессиональный Telegram-бот для отслеживания и напоминания о платежах клиентов за техническую поддержку.

## ✨ Возможности

### 🎯 Основные функции
- **➕ Управление клиентами**: Добавление, редактирование и удаление клиентов
- **💰 Отслеживание платежей**: Автоматический расчет следующей даты платежа
- **🔔 Умные напоминания**: 
  - Напоминания в день платежа
  - Ежедневные уведомления о просроченных платежах
  - Предварительные уведомления за 3 дня (настраивается)
- **📊 Статистика**: Полная статистика по клиентам и платежам
- **📜 История платежей**: Отслеживание всех платежей
- **💾 Резервное копирование**: Автоматическое создание бэкапов
- **📤 Экспорт данных**: Экспорт в CSV формат

### 🔐 Безопасность
- **Аутентификация пользователей**: Доступ только для разрешенных пользователей
- **Защита данных**: Токен бота и база данных защищены
- **Логирование**: Полное логирование всех операций

### 💱 Дополнительно
- **Поддержка валют**: RUB, USD, EUR, KZT, UAH
- **Гибкие интервалы**: Ежемесячно, еженедельно, ежегодно с кастомными значениями
- **Категории клиентов**: Бизнес, Личное, VIP, Тестовый
- **Заметки**: Добавление заметок к каждому клиенту
- **Подтверждение удаления**: Защита от случайного удаления

## 📋 Требования

- Python 3.8 или выше
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))

## 🚀 Установка

### 1. Клонирование репозитория

```bash
git clone <your-repo-url>
cd notification_bot
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка конфигурации

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Отредактируйте `.env` и заполните необходимые параметры:

```env
# Обязательные параметры
BOT_TOKEN=your_bot_token_here
ALLOWED_USERS=123456789,987654321

# Опциональные параметры
CHECK_TIME_HOUR=10
CHECK_TIME_MINUTE=0
ADVANCE_NOTIFICATION_DAYS=3
LOG_LEVEL=INFO
```

**Как получить свой Telegram ID:**
1. Напишите боту [@userinfobot](https://t.me/userinfobot)
2. Скопируйте ваш ID
3. Добавьте его в `ALLOWED_USERS` в файле `.env`

## 🎮 Запуск бота

```bash
python main.py
```

Вы увидите сообщение:
```
✅ Бот запущен и работает!
⏰ Проверка платежей: каждый день в 10:00
📝 Логи сохраняются в: logs/bot.log
```

## 📖 Использование

### Основные команды

- `/start` - Запустить бота и показать главное меню
- `/help` - Показать справку
- `/cancel` - Отменить текущее действие
- `/export` - Экспортировать данные в CSV

### Главное меню

#### ➕ Добавить клиента
1. Нажмите кнопку "➕ Добавить клиента"
2. Введите имя клиента
3. Введите сумму платежа
4. Выберите валюту
5. Введите дату следующего платежа (ДД.ММ.ГГГГ)
6. Выберите интервал платежей
7. Укажите значение интервала
8. Выберите категорию
9. Добавьте заметки (опционально)

#### 📋 Список клиентов
Показывает всех клиентов, сгруппированных по статусу:
- 🔴 Просроченные платежи
- 🟡 Скоро (в течение 3 дней)
- 🟢 Будущие платежи

#### 💰 Отметить оплату
1. Выберите клиента
2. Выберите действие:
   - ✅ Оплачено (автоматически рассчитает следующую дату)
   - ❌ Не оплачено
   - ⏰ Отложить на 3 дня / неделю / месяц

#### ✏️ Редактировать
Позволяет изменить любые данные клиента:
- Имя
- Сумму
- Валюту
- Интервал платежей
- Дату платежа
- Категорию
- Заметки

#### 📊 Статистика
Показывает:
- Общее количество клиентов
- Количество просроченных платежей
- Платежи в текущем месяце
- Ожидаемые суммы по валютам

#### 📜 История
Показывает историю платежей для выбранного клиента

#### 💾 Бэкап
Создает резервную копию базы данных в папке `backups/`

#### ❌ Удалить клиента
Удаляет клиента с подтверждением

## 🔔 Автоматические напоминания

Бот автоматически проверяет платежи каждый день в настроенное время (по умолчанию 10:00).

### Типы уведомлений:

1. **📢 Предварительное уведомление** (за 3 дня)
   ```
   📢 ПРЕДСТОЯЩИЙ ПЛАТЁЖ 🟡
   
   👤 Клиент: Иван Иванов
   💰 Сумма: 5,000.00 ₽
   📅 Дата платежа: 15.02.2026
   ⏰ Осталось: 3 дн.
   ```

2. **🔔 Напоминание в день платежа**
   ```
   🔔 НАПОМИНАНИЕ О ПЛАТЕЖЕ 🟡
   
   👤 Клиент: Иван Иванов
   💰 Сумма: 5,000.00 ₽
   📅 Дата платежа: СЕГОДНЯ (15.02.2026)
   ```

3. **⚠️ Просроченный платеж** (ежедневно до оплаты)
   ```
   ⚠️ ПРОСРОЧЕННЫЙ ПЛАТЁЖ 🔴
   
   👤 Клиент: Иван Иванов
   💰 Сумма: 5,000.00 ₽
   📅 Дата платежа: 15.02.2026
   ⏰ Просрочено на: 5 дн.
   📊 Статус: ⏳ Ожидает оплаты
   ```

Все напоминания о платежах включают быстрые кнопки для отметки оплаты!

## 🗄️ База данных

Бот использует SQLite для хранения данных.

### Таблицы:

**clients** - Информация о клиентах
- id, name, amount, currency
- start_date, next_payment_date
- interval_type, interval_value
- user_id, payment_status
- category, notes
- created_at, updated_at

**payment_history** - История платежей
- id, client_id, payment_date
- amount, currency, status
- notes, created_at

## 🔧 Разработка

### Тестирование логики расчета дат

```bash
python test_logic.py
```

### Включение тестового режима (проверка каждую минуту)

В файле `scheduler.py` раскомментируйте строки:
```python
scheduler.add_job(
    check_payments,
    'interval',
    minutes=1,
    args=[bot],
    id='check_payments_test',
    replace_existing=True
)
```

⚠️ **Внимание:** Не забудьте отключить тестовый режим в продакшене!

## 🐛 Решение проблем

### Бот не запускается

1. Проверьте, что `.env` файл существует и содержит `BOT_TOKEN`
2. Проверьте, что все зависимости установлены: `pip install -r requirements.txt`
3. Проверьте логи в `logs/bot.log`

### Не приходят напоминания

1. Проверьте, что бот запущен
2. Проверьте настройки `CHECK_TIME_HOUR` и `CHECK_TIME_MINUTE`
3. Проверьте логи на наличие ошибок
4. Убедитесь, что есть клиенты с датами платежей

### Ошибка доступа

1. Проверьте, что ваш Telegram ID добавлен в `ALLOWED_USERS`
2. Получите свой ID у [@userinfobot](https://t.me/userinfobot)

### База данных повреждена

1. Остановите бота
2. Восстановите из бэкапа: `cp backups/bot_database_backup_*.db bot_database.db`
3. Запустите бота снова

## 📝 Логи

Логи сохраняются в `logs/bot.log` с ротацией (максимум 10MB, 5 файлов).

Уровни логирования:
- **DEBUG**: Детальная информация для отладки
- **INFO**: Общая информация о работе бота
- **WARNING**: Предупреждения
- **ERROR**: Ошибки
