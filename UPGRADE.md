# 🔄 Руководство по обновлению до версии 2.0.0

Это руководство поможет вам обновить бота с версии 1.0.0 до 2.0.0.

## ⚠️ Важно перед обновлением

1. **Создайте резервную копию базы данных!**
   ```bash
   cp bot_database.db bot_database_backup_$(date +%Y%m%d).db
   ```

2. **Остановите бота** (если он запущен)
   ```
   Нажмите Ctrl+C в терминале где запущен бот
   ```

## 📋 Шаги обновления

### Шаг 1: Обновление кода

Если вы используете git:
```bash
git pull origin main
```

Или скачайте новые файлы вручную.

### Шаг 2: Установка новых зависимостей

```bash
pip install -r requirements.txt --upgrade
```

### Шаг 3: Настройка конфигурации

1. Создайте файл `.env` на основе нового `.env.example`:
   ```bash
   # Если у вас уже есть .env, сохраните BOT_TOKEN
   # Затем создайте новый .env на основе .env.example
   ```

2. Заполните обязательные параметры в `.env`:
   ```env
   BOT_TOKEN=ваш_существующий_токен
   ALLOWED_USERS=ваш_telegram_id
   ```

3. Настройте опциональные параметры (или оставьте по умолчанию):
   ```env
   CHECK_TIME_HOUR=10
   CHECK_TIME_MINUTE=0
   ADVANCE_NOTIFICATION_DAYS=3
   LOG_LEVEL=INFO
   ```

### Шаг 4: Миграция базы данных

Запустите скрипт миграции:

```bash
python migrate_db.py
```

Скрипт:
- Добавит новые колонки в таблицу `clients`
- Создаст таблицу `payment_history`
- Создаст индексы для оптимизации
- Сохранит все существующие данные

Пример вывода:

1. Отправьте боту `/start`
2. Проверьте, что главное меню отображается с новыми кнопками

## 🐛 Решение проблем

### Ошибка: "BOT_TOKEN not found"

**Решение:** Создайте файл `.env` и добавьте ваш токен:
```env
BOT_TOKEN=ваш_токен_здесь
```

### Ошибка: "Unauthorized access"

**Решение:** Добавьте свой Telegram ID в `ALLOWED_USERS`:
```env
ALLOWED_USERS=ваш_id_здесь
```

### Ошибка при миграции

**Решение:** 
1. Восстановите бэкап: `cp bot_database_backup_*.db bot_database.db`
2. Попробуйте миграцию снова
3. Если не помогает, создайте issue

### Старые данные не отображаются

**Решение:**
1. Проверьте, что миграция прошла успешно
2. Проверьте, что вы используете правильный файл базы данных
3. Проверьте логи в `logs/bot.log`

### Бот не отправляет уведомления

**Решение:**
1. Проверьте, что бот запущен
2. Проверьте настройки времени в `.env`
3. Проверьте логи

## 📊 Что изменилось в базе данных

### Таблица `clients`

**Новые колонки:**
- `category` - категория клиента
- `notes` - заметки
- `created_at` - дата создания
- `updated_at` - дата обновления

**Новые индексы:**
- `idx_user_id` - для быстрого поиска по пользователю
- `idx_next_payment_date` - для быстрого поиска платежей
- `idx_payment_status` - для фильтрации по статусу

### Новая таблица `payment_history`

Хранит историю всех платежей:
- `id` - уникальный идентификатор
- `client_id` - ссылка на клиента
- `payment_date` - дата платежа
- `amount` - сумма
- `currency` - валюта
- `status` - статус (paid/unpaid)
- `notes` - заметки
- `created_at` - дата записи
